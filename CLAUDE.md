# CLAUDE.md

## Project Context

This repository contains the website for the **Northeastern Equity Research Group (NERG)**.

NERG is a student-run equity research organization focused on under-covered small and mid-cap companies.

The website should reflect the group's focus on:

- rigorous research
- professional development
- analytical thinking
- institutional-quality work

The site should feel like a **serious academic or research organization**, not a flashy startup landing page.

---

# Required Reading

Before making any changes to the repository, always read:

1. DESIGN.md
2. RESEARCH.md
3. src/content files
4. relevant existing components

Before implementing UI changes:

Summarize DESIGN.md in your own words and follow that summary.

Before implementing or editing content:

Summarize RESEARCH.md in your own words and use it as the content source of truth.

---

# Source of Truth

### DESIGN.md

DESIGN.md defines:

- typography
- layout spacing
- color palette
- UI component consistency
- overall visual tone

All visual and styling decisions must follow DESIGN.md.

---

### RESEARCH.md

RESEARCH.md defines:

- organization mission
- investment universe
- sector coverage
- membership structure
- research standards
- portfolio structure
- organizational messaging

RESEARCH.md is the **authoritative source for all facts about the organization**.

Never invent information that does not exist in RESEARCH.md.

---

# Design Philosophy

The site should feel:

- minimal
- structured
- credible
- professional
- content-first

Avoid flashy or trendy design patterns.

Preferred design qualities:

- strong typography hierarchy
- generous whitespace
- restrained color usage
- simple card layouts
- subtle hover interactions

Avoid:

- gradients
- glassmorphism
- animated backgrounds
- excessive motion
- decorative UI elements
- startup marketing aesthetics

---

# Code Guidelines

Preferred technologies:

- Next.js
- TypeScript
- Tailwind CSS

General expectations:

- functional React components
- typed props
- small reusable components
- minimal dependencies
- readable and maintainable code
